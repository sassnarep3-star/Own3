Method & sources

Rules this site follows

  1. A value is shown only if it was read on an official page on 2026-11-01. Otherwise the cell is blank and the row says unverified. Nothing is inferred or filled in.
  2. Every table row carries an official link. Links on news, press-release, social, affiliate or forum domains are never accepted as official; rows with no other source are held out and flagged.
  3. The old ledger's own claims are kept only in data/competitions.json → upstream for audit; the site never renders them as facts.
  4. Contradictions between the old ledger and an official page are published on the Flagged for Review page.

Data pipeline

  1. Source: karagemop466-tech/FreeMoneyApps at commit 466f7c1; assets/data.js copied to data/upstream/data.js (SHA-256 13986a17b8b9aa7b…).
  2. Verification: hand-recorded in data/verification.json (page URL, fields confirmed, notes, discrepancies).
  3. Audit: tools/build_data.js computes automatic flags and writes data/competitions.json.
  4. Site: tools/build_site.js writes the static HTML; scripts/validate-catalog.mjs checks it (CI runs it on every push and pull request).

Limits

  • Pages were read with a page-text fetcher; scripts did not run, so values rendered by JavaScript may be missing (these are left blank, not guessed).
  • Long rules were read in parts. Fields in unread parts are blank.
  • "Closing soon" labels such as "8 days to go" are quoted from the official listing as of 2026-11-01.
  • Analyst notes on the Best bets page are judgment and are labelled as such.

4. Source quality

  • 20 rows have a source the old ledger tags "official" that sits on a third-party domain (press-release wires, news sites, social posts, aggregators). These are not accepted as official links here.
  • 14 rows have no usable official source and are held out of the tables (listed on the Flagged page). Another 11 rows are shown with the operator's own site as an unchecked link only.
  • 19 rows share a signup URL with other rows (11 third-party FPL league listings all point to fantasy.premierleague.com), so that link is the platform, not the league.
  • 13 rows' "Official site" button is on a different domain than the row's own official source.

6. Review of the source site and repository

  • Usability. The old site's home page renders all 206 entries as expanded cards on one page and states "No search box, no filters". Our fetch of the page text spans 28 chunks. We did not test it on physical phones, so mobile defects are not itemised — the structural cause (very long single page, no filtering) is.
  • Contradictory documents. Its review page says the ledger "runs to 119 listings" while the data and README say 206; it also lists Reddit threads (r/beermoney, r/sweepstakes, r/FantasyPL, r/EarnExtraIncome) among its sources, although its own README source-tier table says forum/Reddit is "context only". (Older documents such as 100_VERIFIED_CONTESTS.md are clearly labelled superseded upstream and are not counted as an irregularity.)
  • Links. Broken or dead links found: Zindi's rules link (HTTP 404) and Challenge.gov (platform sunset 2026-03-30). Reachability of the remaining external links could not be tested from this environment — see the method page.
  • Source repo pinned at 466f7c1; a copy of its data file is in data/upstream/data.js (SHA-256 recorded in data/competitions.json).

7. Implications for an AI-assisted entrant

  • The largest verified prizes are in code/ML and hackathon competitions (Kaggle, ARC Prize, DrivenData, Devpost). Those are where an AI coding agent is most plausibly useful — but the AI-tool policy of each is unverified.
  • Judged creative contests may forbid AI: Winning Writers' official rules prohibit AI-generated text.
  • Pick'em contests (ESPN, CBS) have large verified prize pools but also large public fields; no odds were published on the pages read, so their expected value is unknown.
